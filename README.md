# TrumpGPT — An Unofficial AI Satire

手机优先的英语政治喜剧 PWA。所有回答均为虚构。界面使用原创麦克风插画。三个模式各有开场白、三个示例问题和十二条喜剧答复。用户输入用于在本机匹配主题，同一组答复遍历完后才会重复。

## 启动与测试

运行环境为 Python 3（本地静态服务器）和 Node.js 22 或更高版本（自动化测试）。应用本身仅需现代浏览器，无构建步骤。

```sh
python3 -m http.server 8000 --directory docs
```

电脑浏览器打开 `http://localhost:8000/`。同一局域网内的手机可打开 `http://电脑局域网IP:8000/` 测试聊天。安装和离线功能需要 HTTPS 或本机 localhost。手机完整测试可使用下方 GitHub Pages 地址。

```sh
node --test tests/*.test.mjs
```

## GitHub Pages 部署

1. 在 GitHub 创建一个全新的空仓库，例如 `trumpgpt`。从本项目根目录把它添加为 origin，并推送 main。
2. 在该仓库的 Settings → Pages 中选择 Deploy from a branch，选中 main 和 /docs，保存。
3. 等待 Pages 部署完成，在手机打开 `https://<账号>.github.io/<仓库名>/`。资源、清单和 Service Worker 均使用相对路径。
4. 首次联网打开，等待静态资源缓存完成。iPhone 用 Safari 的分享菜单选择“添加到主屏幕”。Android Chrome 可点页面底部 Install app 或使用浏览器安装菜单。关闭页面、断网、从图标启动并发送问题，可验证离线工作。

发布静态资源更新时，递增 docs/sw.js 中的缓存版本。关闭旧标签页再打开，可让新版本接管。

## 使用

选择模式后可输入问题或点击示例。Enter 发送，Shift+Enter 换行。切换模式保留本页各模式的记录与草稿，刷新页面会重置。Copy conversation 复制当前模式的完整对话，并在首行附上虚构声明，可粘贴到 X。长对话可自行摘录并保留首行声明。

## V1 边界与升级路线

V1 使用固定原创文本，所有处理在设备内完成，无 API 密钥。真人语音、实时模型、账号、数据库和跨会话历史不在本版范围内。

如需升级，可将问题、模式和少量上下文发往独立的 HTTPS 后端，在服务端保管模型密钥、限流并设置费用上限。后端应限制内容为虚构喜剧，检查请求和输出以避免冒充官方、伪造新闻和选举动员。断网、超时或超出预算时继续使用本地模板。上线前用三个模式的样例和对抗性提问验证内容及分享声明。
